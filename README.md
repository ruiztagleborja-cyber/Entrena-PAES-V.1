# Entrena PAES

Sitio estático de práctica PAES Matemática M1 y M2: 302 ejercicios de las guías, sesiones recomendadas según los errores de cada persona y guías imprimibles.

- `index.html`: la aplicación completa.
- `data/ejercicios.json`: banco de ejercicios.
- `img/`: figuras de los ejercicios.

El progreso de cada persona se guarda en el navegador del dispositivo que usa.

## Publicar en Vercel
Opción A (sin instalar nada): sube esta carpeta a un repositorio nuevo de GitHub y en vercel.com elige Add New → Project → importa el repositorio → Deploy.

Opción B (con Node instalado): en esta carpeta ejecuta `npx vercel --prod`.
